==> umbree-release-manage --help

umbree-release-manage — the Umbree release catalog service

Usage:
  umbree-release-manage <command> [flags]

Commands:
  serve                    apply pending migrations, then serve the release intake and the operator console
  migrate                  with --check, report the migrations ledger against this binary; writes nothing
  backfill                 once per component: catalog the releases already on the public surface, verified, writing the catalog only
  admin mark-yanked <id>   mark a public row yanked in the catalog only, audited; for a manifest already pulled by hand
  admin add <name>         add a console admin; prints its TOTP enrolment once, and only here
  admin list               list the console admins and their open sessions; shows no secret
  admin remove <name>      remove a console admin and end its sessions
  admin reset-totp <name>  replace an admin's second factor, print the new enrolment once, and end its sessions
  admin unlock <name>      clear an admin's failed sign-in count so it can sign in again, audited
  docs                     print the command reference that docs/manage-help.txt holds

umbree-release-manage <command> --help prints that command's flags.

==> umbree-release-manage serve --help

Usage:
  umbree-release-manage serve [flags]

apply pending migrations, then serve the release intake and the operator console

Flags:
  --data-dir <dir>             the dir holding the catalog (required; no default) (env UMBREE_MANAGE_DATA_DIR)
  --gated-bucket <bucket>      the private gated bucket; must differ from --public-bucket (env UMBREE_R2_GATED_BUCKET)
  --listen <address>           the address to bind (default 127.0.0.1:8787, loopback) (env UMBREE_MANAGE_LISTEN)
  --public-base-url <url>      the public download url the manifests are served from (env UMBREE_PUBLIC_BASE_URL)
  --public-bucket <bucket>     the public download bucket (env UMBREE_R2_BUCKET)
  --r2-account <account>       the R2 account id (env UMBREE_R2_ACCOUNT)
  --r2-creds <file>            the file holding the R2 token (env UMBREE_R2_CREDS)
  --secret-key <file>          the operator-provisioned file that seals TOTP secrets: an absolute, clean path to a regular 0600 file of 32 random bytes; never created here (required) (env UMBREE_MANAGE_SECRET_KEY)
  --trusted-proxy <ip>         the TLS front's ip as this service sees it; only a peer with this exact address may name the client in X-Forwarded-For (rightmost entry). Unset: no forwarded header is read (env UMBREE_MANAGE_TRUSTED_PROXY)
